## 只写在条款和购买页角落里的限制

GreenCloudVPS 的低价有四个前提条件，官方写在服务条款和套餐页上，但很多测评不提。这几条直接影响你要不要买。

**第一，退款政策要分两种情况。** 官方条款写明：新客户可以对首个 VPS 套餐在注册后 7 天内申请退款，但有三个排除项——促销套餐不退、独立服务器不退、加密货币付款不退；另外已用掉 10% 及以上分配带宽的服务也不在退款范围内。所以“促销价不退款”是真的，“绿云完全不退款”是误传。想先试用的读者，用月付常规档走 7 天窗口比直接冲年付特价稳妥得多。

**第二，香港 VPS 对中国大陆的直连带宽只有 10Mbps。** 这是官方在自己套餐页上的标注（对比之下日本是 1Gbps Best-Effort）。10Mbps 意味着日常建站、API、轻量代理够用，但如果你幻想的是大带宽回国跑流媒体，这个节点会让你失望。流量不够加购也要注意区域差价：官方条款里 APAC 区加带宽是 **$15/TB/月**，美欧区只要 $3/TB/月——差了五倍，这也是很多文章不会告诉你的隐藏成本。

**第三，只支持 Linux（两条主流线均是）。** Budget KVM 和 Ryzen KVM 都只提供 Linux OS，没有 Windows 镜像，想开远程桌面的用户直接排除。绿云另有 Budget Windows VPS 和 Managed Windows VPS 产品线（$32/月 起），但那是另一套价格体系。

**第四，unmanaged（无托管）。** 官方条款原话是只提供硬件功能支持，软件支持限于订购时选择的默认安装。系统被你玩坏了、软件报错，工单帮不上忙。工单响应本身不慢（第三方测评记录平均约 12 分钟），但响应的内容是硬件层面的。

还有两个使用层面的小点：Ryzen KVM 线的香港 DC2（HK2）端口为 1Gbps（美洲/欧洲线才是 10Gbps），流量额度约为同配置美洲位置的一半——比如 4GB 档在香港给 2TB，美洲给 4TB；硬件上香港 Budget KVM 用的是 Xeon E5v4 + SSD RAID-10，和部分美国位置的 EPYC + NVMe 有代差，对 CPU 单核性能敏感的负载要有预期。

## 常见问题

**GreenCloudVPS 香港节点适合给中国大陆用户访问吗？** 适合低延迟访问，不适合大带宽。香港位置对大陆的物理延迟有天然优势，但官方标注对大陆直连带宽只有 10Mbps，静态网站、API 服务、轻量应用没问题，大流量场景要另选。

**买错了能退吗？** 分情况：新客户首个 VPS 有 7 天退款窗口（需已用带宽不超过 10%）；促销套餐、加密货币付款不退。只打算短期试用的读者，选月付常规档比年付特价保险。

**能装 Windows 吗？** Budget KVM 和 Ryzen KVM 都只有 Linux。需要 Windows 的用户要看绿云的 Windows VPS 产品线（$32/月 起）或选 LightNode、EDIS 这类提供 Windows 镜像的商家。

**为什么同一个套餐价格到处不一样？** 绿云按机房分货定价，同配置在不同位置价格可能不同，特价库存售完即止，且促销价仅适用于新订单。你看到的任何价格都对应“某个位置 + 某个时间点”的组合。

**一个 IP 够用吗？** 每个套餐默认含 1 个 IPv4 和 IPv6（香港为 /112 前缀）。加购 IP 在 APAC 区是 $3/IP/月，每台最多 5 个。
